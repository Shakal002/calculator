# HTML Калькулятор

Простой веб-калькулятор на чистом HTML, CSS и JavaScript.
Реализован по руководству Zell Liew «How to build an HTML
calculator app from scratch using JavaScript» (freeCodeCamp).

## Функционал
- Ввод цифр и десятичной точки
- Операции: +, −, ×, ÷
- Очистка (AC)
- Вычисление результата (=)

## Стек
- HTML5
- CSS3 (Grid)
- JavaScript (Vanilla, event delegation)

## Запуск локально
Открыть `index.html` в браузере.
